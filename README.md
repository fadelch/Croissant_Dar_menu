# Croissant Dar — كروسان الدار

Phase 1 foundation for the Croissant Dar restaurant website.

## Local development

```bash
npm install
npm run dev
```

The application uses Next.js App Router, TypeScript, Tailwind CSS, ESLint, and
Zod. Firebase and all menu, cart, admin, and authentication behavior are
intentionally deferred to later phases.
